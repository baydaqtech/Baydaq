# هوية بيدق تكنولوجي: «البيدق المبني»

بيدق مبني من كتل متراكمة، كل كتلة أعرض من التي فوقها، ورأسه ذهبي. يرمز إلى البناء خطوة بخطوة.

## الألوان

| الاسم | القيمة | الاستخدام |
|---|---|---|
| جوز | `#3B2414` | جسم البيدق والنص على الخلفيات الفاتحة |
| نحاسي | `#C8902F` | الرأس والخط الفاصل على الخلفيات الفاتحة |
| نحاسي ساطع | `#D6A24E` | الرأس على الخلفيات الداكنة |
| عاجي | `#F6EBD6` | جسم البيدق والنص على الخلفيات الداكنة |
| بني هادئ | `#6B5238` | كلمة «تكنولوجي» على الخلفيات الفاتحة |

الخط: **Alexandria**، بوزن 900 لكلمة «بيدق» ووزن 300 لكلمة «تكنولوجي».

## الملفات

| الملف | متى تستخدمه |
|---|---|
| `baydaq-logo-horizontal.svg` | الشعار الأساسي: رأس الموقع، والمستندات، والعروض |
| `baydaq-logo-horizontal-light.svg` | نفس الشعار للخلفيات الداكنة |
| `baydaq-logo-stacked.svg` / `-light` | المساحات المربعة أو الضيقة: الملصقات، وصفحات التواصل الاجتماعي |
| `baydaq-mark.svg` | الرمز وحده دون الاسم |
| `baydaq-mark-light.svg` | الرمز وحده للخلفيات الداكنة |
| `baydaq-mark-mono.svg` | لون واحد: الختم، والطباعة بلون واحد، والحفر |
| `baydaq-app-icon.svg` و `favicon.svg` | أيقونة التطبيق وأيقونة الموقع في المتصفح |
| `baydaq-avatar.svg` و `png/whatsapp-640.png` | صورة الحساب: واتساب، ولينكدإن، وإكس، وإنستغرام. مربعة بخلفية كاملة دون شفافية، والرمز في الوسط بحيث يبقى كاملاً عند القص الدائري |
| `baydaq-avatar-name.svg` و `png/whatsapp-640-name.png` | نفس صورة الحساب مع اسم «بيدق تكنولوجي» تحت الرمز |
| `png/` | نسخ جاهزة بكل الأحجام: 16 إلى 1024 بكسل، و`apple-touch-icon.png` (180)، و`icon-192.png`، و`icon-512.png` |

## ملاحظات

- ملفات الشعار الكامل تحتوي الخط مضمّناً داخلها، فتظهر بشكل صحيح في المتصفحات. إذا فتحتها في Illustrator أو Figma، **حوّل النص إلى أشكال (Outline)** قبل الطباعة أو الإرسال للمطبعة.
- اترك حول الشعار مساحة فارغة لا تقل عن **قطر الرأس الذهبي**.
- لا تغيّر الألوان، ولا تمطّ الشعار، ولا تضعه على خلفية مزدحمة.
- أصغر حجم للرمز وحده 16 بكسل، وأصغر عرض للشعار الكامل 120 بكسل.
- لإعادة توليد ملفات SVG بعد تعديل الرمز، شغّل الأمر: `bash brand/source/build.sh brand`. الشيفرة والخطوط المستخدمة موجودة في `source/`.
